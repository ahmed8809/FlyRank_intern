# Research-page design notes

For the capstone page, I reviewed web-native research/article patterns rather than exporting the notebook directly.

## Findings

- Distill's web-native research guidance emphasizes a focused reading column, larger visual layouts when needed, and interactive or explanatory media where it improves understanding.
- Research on interactive articles argues that digital research communication can use annotations, interaction, and progressive explanation to reduce cognitive load and improve recall.
- Observable's recent data-storytelling guidance emphasizes clarifying the question first, selecting only the visualizations that carry the story, adding context, annotating important points, and writing actionable chart titles.
- The 2026 Paper2Web work reinforces that research websites should make core content easy to navigate and combine completeness with visual clarity and useful interaction.

## Design choice

This capstone uses a restrained research-artifact style instead of a dashboard:
- one clear research question above the fold;
- a short abstract and headline findings;
- sticky section navigation for fast scanning;
- metric cards for the few numbers that matter;
- three/four charts with one message each;
- short paragraphs and tables for methodology;
- explicit "what this does not prove" language;
- reproducibility and data credit at the end.

The page is intentionally static and dependency-light so it can be deployed directly through GitHub Pages.
